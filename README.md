# 宝宝辅食添加时间表（0–24 月龄）

母婴类博主「母婴数据实验室」系列第 1 弹。按月龄的辅食添加可视化信息图，可截图分享。

## 功能
- 按月龄时间线：0–5 月纯乳 → 满 6 月第一口 → 7/8/9/10/11 月 → 1 岁 → 1–2 岁
- 每张卡片含：性状、餐次、✅ 可以吃、⛔ 禁忌/注意、★ 本月重点、💡 小贴士
- 交互筛选「宝宝类型」：普通 / 过敏高风险 / 早产 / 已确诊过敏（自动高亮过敏原、显示对应提醒）
- 单卡 / 整页一键导出 PNG（html2canvas）

## 内容依据
《中国居民膳食指南（2022）》、WHO 婴幼儿喂养建议、通用儿科辅食共识。
⚠️ 仅供参考，早产 / 过敏史 / 特殊体质请遵医嘱。

## 本地预览
直接用浏览器打开 `index.html` 即可。
